# How to use:

There is a button in the edit menu of the level editor, click on it to use the mod. You'll be instructed to select an image to import to GD. 
I suggest creating your pixel art on a site like Piskel, and then exporting it as a .png for ideal compatibility. 
I advise not to import large images on low-end devices, since this can cause extreme lag and/or game crashes. 
At default, the mod is limited to 40,000 pixels, however this can be decreased or increased in the mod settings too (from 100 to 80,000 pixels). 
Furthermore, there is an option to remove this limit altogether, however it's not recommended for the same reasons highlighted before. 
There are also mod settings that allow you to choose between two optimisation methods, along with a setting that allows you to use the old 2.1 pixel objects. 
Finally, there are also other various options that you can change as well, to your liking.
